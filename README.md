# BredOS 🍞
A Debian 13 based Linux distribution with its own desktop, built as a bootable ISO.

## Building
Go to the **Actions** tab, choose **Build BredOS ISO**, press **Run workflow**.
When it finishes, download the `BredOS-iso` artifact.
Locally: run `sudo bash iso/build.sh` inside a Debian 13 system.

## Live session
Username `bread`, password `live`. Super+Space launcher, Super+Enter terminal, Super+E files.

## Layout
`iso/` ISO build config · `theme/` visual assets · `shell/` `compositor/` `apps/` `installer/` future custom components · `docs/` notes
